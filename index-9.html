📘 Potências

Uma potência representa uma multiplicação repetida de fatores iguais.

aⁿ = a × a × ... × a

Em 2⁴, o número 2 é a base e o número 4 é o expoente.

2⁴ = 2 × 2 × 2 × 2 = 16

1. Produto de potências com a mesma base

aᵐ × aⁿ = aᵐ⁺ⁿ

Somam-se os expoentes.

3² × 3³ = 3⁵ = 243

2. Quociente de potências com a mesma base

aᵐ ÷ aⁿ = aᵐ⁻ⁿ (a ≠ 0)

Subtraem-se os expoentes.

5⁴ ÷ 5² = 5² = 25

3. Potência de uma potência

(aᵐ)ⁿ = aᵐˣⁿ

Multiplicam-se os expoentes.

(2³)² = 2⁶ = 64

4. Expoente zero e negativo

a⁰ = 1 (a ≠ 0)
a⁻ⁿ = 1/aⁿ

Exemplos:

7⁰ = 1
2⁻³ = 1/2³ = 1/8

Exemplo resolvido

Simplifica 2³ × 2².

  1. As bases são iguais: mantemos a base 2.
  2. Somamos os expoentes: 3 + 2 = 5.
  3. Resultado: 2⁵ = 32.
Dica: só somas ou subtrais expoentes diretamente quando as bases são iguais.

√ Radicais

Um radical representa uma raiz. A raiz quadrada de um número é o valor que, multiplicado por si próprio, dá esse número.

√36 = 6, porque 6 × 6 = 36

Na raiz cúbica, procuramos o número que multiplicado três vezes por si próprio dá o radicando.

∛27 = 3, porque 3 × 3 × 3 = 27

1. Raízes exatas

Memoriza alguns quadrados perfeitos:

√4 = 2 · √9 = 3 · √16 = 4
√25 = 5 · √49 = 7 · √64 = 8
√81 = 9 · √100 = 10

2. Simplificação de radicais

Procura um fator que seja um quadrado perfeito.

√12 = √(4 × 3)
= √4 × √3 = 2√3
Outro exemplo: √50 = √(25 × 2) = 5√2.

3. Raízes cúbicas

∛8 = 2
∛64 = 4
∛125 = 5

Porque 2³ = 8, 4³ = 64 e 5³ = 125.

4. Operações com radicais semelhantes

Quando os radicais têm a mesma parte radical, somam-se ou subtraem-se os coeficientes.

2√3 + 4√3 = 6√3
7√2 − 3√2 = 4√2
Atenção: √2 + √3 não é igual a √5.

Exemplo resolvido: √125

  1. Decompõe: 125 = 25 × 5.
  2. Separa as raízes: √125 = √25 × √5.
  3. Calcula a raiz exata: √25 = 5.
  4. Resultado simplificado: 5√5.
